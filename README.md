# Rent-space
<a target="_blank" href="https://privatart.github.io/rent-space/">Rent-space</a>

This is the website of a fictional real estate agency where you can search for residential or commercial properties for rent. You can save listings to Your list, delete them, and filter them by posting date or price. Inspired by my own search for an apartment to rent in Warsaw and with the goal of continuing what has become just a hobby - web development.
